# AI Phishing Detector

An AI-powered phishing detection web application built using Python, FastAPI, OpenAI, HTML, CSS, and JavaScript.

## Features

* Analyze suspicious emails for phishing risk
* AI-generated risk assessment
* Risk level classification (High, Medium, Low)
* Security recommendations
* Web-based user interface

## Technologies Used

* Python
* FastAPI
* OpenAI API
* HTML
* CSS
* JavaScript
* Git
* GitHub

## How It Works

1. User pastes suspicious email content.
2. Frontend sends the email text to the FastAPI backend.
3. Backend sends the content to the OpenAI API.
4. AI analyzes the email.
5. Results are displayed in the browser.
